# TASK-011 — วางแผนปลูก: ปักขอบเขตแปลงบนแผนที่ + ระยะปลูก → ตำแหน่งต้นไม้

**สถานะ:** 🟡 เสร็จ ทดสอบ end-to-end บน local แล้ว (2026-11-23 · แก้ไขแผน 2026-11-24) · **repo / ลำดับ release:** st-contracts 0.3.0 → 0.4.0 → st-garden-service → st-mfe-garden

ที่มา: สคริปต์ Colab ของผู้ใช้ (Leaflet + shapely + pyproj + folium) — port เป็น TypeScript ตาม stack

## ฟีเจอร์
1. หน้า "วางแผนปลูก" (แท็บข้าง "นับต้นไม้จากภาพ" ใน mfe-garden) → วางแผนใหม่
2. แผนที่ดาวเทียม (MapLibre + Esri — CONF-006): ไปที่พิกัด / ตำแหน่งปัจจุบัน → คลิกปักมุมแปลงตามลำดับ (ย้อน/ล้างได้)
3. ระยะปลูก (ม.) → พรีวิวอัตโนมัติ (debounce + switchMap): จุดต้นไม้บนแผนที่, จำนวนต้น/แถว, พื้นที่ ไร่-งาน-ตร.วา
4. ตั้งชื่อ → บันทึก → หน้าดูแผน (แผนที่ + ตารางพิกัด + คลิกจุดดูพิกัด) · CSV คอลัมน์เดียวกับ Colab (`tree_id, order_no, row, col, latitude, longitude`)

## วิธีคำนวณ (เหมือน Colab)
- [lng, lat] → UTM (โซนจากลองจิจูดเฉลี่ย, EPSG:326xx) — คำนวณเป็นเมตรเสมอ
- มุมแนวแถว = ขอบแรก (มุม 1→2) · หมุนแปลงรอบจุดศูนย์ถ่วงให้ขอบแรกอยู่แนวนอน → ตีตารางเริ่มห่างขอบครึ่งระยะปลูก จากบนลงล่าง ซ้ายไปขวา → เก็บเฉพาะจุดข้างในแปลง (ไม่รวมบนเส้นขอบ) → หมุนกลับ → [lng, lat]
- แถว/คอลัมน์ = ตำแหน่งในตารางเต็มกรอบ (ช่องนอกแปลงข้ามเลข — เหมือน Colab)
- พื้นที่ = shoelace บน UTM · รูปแปลงตรวจด้วย PostGIS `ST_IsValid` ก่อนคำนวณ (ขอบตัดกันเอง → 422 `BOUNDARY_INVALID`)
- จำกัด 20,000 ต้น/แผน · ขอบเขต ≤ 200 มุม · ระยะปลูก 0.5–100 ม.

## ต่างจาก Colab (ตั้งใจ)
- ภาพดาวเทียม Esri แทน tile ของ Google (`mt1.google.com/vt` — ดึง tile ตรงขัดเงื่อนไข Google) — CONF-006
- ยังไม่มีค้นหาชื่อสถานที่ (Colab ใช้ OSM Nominatim — บริการภายนอกมีเงื่อนไขการใช้ ต้องเปิด CONF ถ้าจะใช้) · ค้นด้วยพิกัดได้
- บันทึกลง DB (ไม่ใช่แค่ CSV) · คำนวณที่หลังบ้าน
