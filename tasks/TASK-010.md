## ขั้นตอนของฟีเจอร์
1. ผู้ใช้อัปโหลดภาพถ่ายมุมสูง (โดรน/ภาพตั้งฉาก) ของแปลง → bucket `garden-photos` ผ่าน signed URL
2. ผู้ใช้คลิกขอบเขตแปลงบนภาพ (≥ 3 จุด)
3. หลังบ้านหาจุดต้นไม้ (blob สีเข้ม + fallback จุดต่ำสุดเฉพาะที่) → ตัดจุดนอกขอบเขต/จุดซ้ำ → ระยะถึงต้นที่ใกล้สุด
4. หมุนตารางตามกรอบพื้นที่น้อยสุด → แบ่งแถว → ให้เลข `T_001…` เรียงแถวละซ้ายไปขวา + เส้นกริด
5. หน้าบ้านแสดงภาพ + จุด + กริด + ตาราง (ซูม/เลื่อน คลิกจุดแล้วตารางเลื่อนตาม) และ (ภายหลัง) แก้จุดเองได้

## ต่างจากสคริปต์ต้นฉบับ (ตั้งใจ)
- perspective transform จากกรอบ → สี่เหลี่ยมตั้งตรงขนาดเท่ากัน = การหมุน จึงเขียนเป็นการหมุนตรง ๆ · มุมกริดเลือกในช่วง (-45°, 45°] (ต้นฉบับเรียงมุมด้วยผลบวก/ผลต่างพิกัด ซึ่งสลับด้านได้เมื่อเอียงใกล้ 45°)
- มาตราส่วนเป็น **ตัวเลือก** (`metersPerPixel` / `assumedSpacing` / `none`) แทนการตั้ง `ACTUAL_SPACING_M = 4.0` ตายตัว — ดู MOCK-001
- ประมวลผลเฉพาะกรอบของขอบเขตแปลง (+16 px) ไม่ใช่ทั้งภาพ
- เพิ่ม `column` และ `nearestTreeId` ในผลลัพธ์ · ตัด `warped_x/y` (ใช้ภายใน)
- ค่า area/circularity คิดจากพิกเซล ไม่ใช่ contour ของ OpenCV → จำนวนที่นับได้อาจต่างจาก Colab เล็กน้อยในภาพจริง

## ข้อจำกัดของอัลกอริทึม (ต้องบอกผู้ใช้ในหน้าจอ)
- ค่า threshold ตั้งไว้สำหรับทรงพุ่มสีเข้มบนพื้นสว่าง ขนาด 30–600 px² — ภาพความละเอียดอื่น/พื้นหญ้าเขียวทึบ/ทรงพุ่มชนกันจะนับผิด → ต้องมีโหมดแก้จุดเอง
- การแบ่งแถวสมมติว่าปลูกเป็นตารางสี่เหลี่ยม — ปลูกสลับฟันปลา/ไม่เป็นแถวจะได้เลขแถวไม่ตรง
- การผูกแผนที่ใช้ affine → ภาพต้องถ่ายตั้งฉาก · ภาพเฉียง/พื้นลาดชันมากจะคลาด (แสดง `rmsErrorM` ให้ผู้ใช้เห็น) · ระยะบน UTM ต่างจากระยะบนพื้นจริงไม่เกิน ~0.04% ในไทย
