# BUG-002 — คอลัมน์ geometry ที่ drizzle สร้างไม่มี SRID

**สถานะ:** ✅ แก้แล้วก่อน apply (2026-11-23) · **repo:** st-garden-service

## อาการ
migration ที่ `drizzle-kit generate` สร้างจาก `geometry('geom', { type: 'point', mode: 'tuple', srid: 4326 })` ออกมาเป็น `"geom" geometry(point)` — ไม่มี 4326 ขัดกฎ "geometry เก็บ SRID 4326"

## สาเหตุจริง
`geometry()` ของ drizzle-orm 0.45 / drizzle-kit 0.31 ไม่ใส่ srid ลง DDL · และ insert แบบ tuple ส่ง WKT ไม่มี SRID (ถ้าคอลัมน์มี SRID จะ error)

## วิธีแก้
`src/db/schema.ts` ประกาศ `customType` ที่ `dataType` = `geometry(Point, 4326)` · เขียนด้วย `` sql`ST_SetSRID(ST_MakePoint(${lng}, ${lat}), 4326)` `` · อ่านด้วย `ST_X/ST_Y` ใน repository · ลบ migration เดิม (ยังไม่ apply) แล้ว generate ใหม่ · ตรวจแล้ว `geometry_columns` = POINT srid 4326

## กันไม่ให้เกิดซ้ำ
คอลัมน์ geometry ใช้ customType แบบเดียวกัน (ดู `st-garden-service/src/db/schema.ts`) · หลัง generate ให้ตรวจ DDL ว่ามี `, 4326)` (กฎใน CLAUDE.md)
