# BUG-001 — `drizzle-kit migrate` ล้ม: schema "<ชื่อ>" already exists

**สถานะ:** ✅ แก้แล้ว (2026-11-23) · **repo:** st-parcel-service, st-listing-service, st-garden-service, st-notification-service

## อาการ
`bun run db:migrate` ครั้งแรก → `error: script "db:migrate" exited with code 1` (code `42P06` schema already exists) · ไม่มี migration ถูก apply

## วิธีทำให้เกิด
service ใหม่ที่ `drizzle.config.ts` ตั้ง `migrations: { schema: '<schema ของ service>' }` แล้วรัน migrate กับ DB ว่าง

## สาเหตุจริง
drizzle-kit สร้าง schema ที่ระบุใน `migrations.schema` ก่อน (เพื่อเก็บตาราง `__drizzle_migrations`) → migration แรกที่ drizzle-kit generate มี `CREATE SCHEMA "<ชื่อ>";` จึงชน

## วิธีแก้
แก้ `drizzle/0000_init.sql` ทั้ง 4 service เป็น `CREATE SCHEMA IF NOT EXISTS "<ชื่อ>";` — แก้ได้เพราะยังไม่เคย apply ที่ไหน (ตรวจแล้ว `__drizzle_migrations` ว่างทุกตัว)

## กันไม่ให้เกิดซ้ำ
service ใหม่: หลัง `db:generate` ครั้งแรก เปลี่ยน `CREATE SCHEMA` ในไฟล์ migration แรกเป็น `IF NOT EXISTS` ก่อน apply (กฎใน CLAUDE.md)
