# CONF-001 — Native Federation บนแอปมือถือ (Capacitor) โหลด remote จากไหน

**สถานะ:** ⏸️ เลื่อน (ผู้ใช้ 2026-11-23: ทำเว็บก่อน) — ตัดสินใจตอนเริ่ม TASK-009 · **กระทบ:** TASK-009, st-shell · **ผู้ตัดสินใจ:** ผู้ใช้

## ปัญหา
บนเว็บ shell โหลด remote ผ่าน URL ใน `federation.manifest.json` ได้ปกติ แต่แอป Capacitor รันไฟล์ในเครื่อง:
- ถ้าโหลด remote จากเซิร์ฟเวอร์ → ใช้ไม่ได้ตอนออฟไลน์/เน็ตช้า, ต้องเปิด https + CORS ให้ origin ของแอป (`capacitor://localhost`, `https://localhost`), และต้องตรวจกฎ store เรื่องดาวน์โหลดโค้ดมารันภายหลัง (App Store Review Guidelines ข้อ 2.5.2 / 4.7 — ตรวจฉบับล่าสุดตอนส่งแอป)
- remote ที่ deploy ใหม่ต้องเข้ากันได้กับ shell เวอร์ชันที่ผู้ใช้ติดตั้งค้างไว้ (shared library ต้องตรงกัน)

## ทางเลือก
| | วิธี | ข้อดี | ข้อเสีย |
|---|---|---|---|
| A | **build มือถือรวม remote ไว้ใน assets ของแอป** (manifest ชี้ path ในเครื่อง) · เว็บโหลดจาก URL | ออฟไลน์ได้, ผ่าน store ง่าย, เวอร์ชันล็อกพร้อมกัน | ต้องมีขั้น build ที่ดึง dist ของทุก remote มารวม |
| B | มือถือโหลด remote จากเซิร์ฟเวอร์เหมือนเว็บ | อัปเดตโดยไม่ส่ง store | ข้อเสียทั้งหมดด้านบน |
| C | Capacitor live update (เช่น Capgo/Appflow) ส่ง bundle ทั้งก้อน | อัปเดตเร็ว | มีค่าใช้จ่าย/ผูกผู้ให้บริการ |

## ข้อเสนอ
**A** สำหรับ PoC — เว็บได้ประโยชน์ของ federation เต็มที่ มือถือได้ความเสถียร
